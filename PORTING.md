# SMF 1.1.21 → Go port: status

Plan: `~/.claude/plans/graceful-scribbling-kazoo.md`. Verify with `go build ./... && go vet ./... && go test ./...` from `go/`.
Manual run: `go build -o /tmp/smf ./cmd/smf && cd /tmp/smftest && /tmp/smf` (test instance lives in /tmp/smftest, assetdir points at the repo root).

Conventions:
- One Go file per PHP file: `Sources/MessageIndex.php` ↔ `internal/app/messageindex.go`; templates `Themes/default/X.template.php` ↔ `tpl_x.go`.
- Templates are hand-ported echo-by-echo via `c.O(...)` — byte-identical output is the requirement, including tabs/newlines inside string literals.
- `$context` chrome → fields on `Ctx` (request.go); page data → per-controller struct in `c.Page`.
- `$txt` → `c.Txt("key")` (numeric keys are strings: `c.Txt("34")`); language data generated by `go run ./tools/txtgen -langdir ../Themes/default/languages -out internal/lang/english_gen.go index Errors ...` — regenerate with more files as they're needed.
- PHP exit/die/redirect → `panic(smfExit{})` via `c.exit()` / `c.obExit()` / `c.redirectExit()`; recovered in router.go dispatch.
- Queries keep SMF table/column names; `a.Q()` substitutes `{$db_prefix}`. MySQL FIND_IN_SET/INET_ATON are registered as SQLite functions (sqlfuncs.go). `LIMIT a,b` → `LIMIT b OFFSET a`; bind `?` parameters instead of inlined strings.
- PHP `empty()` → `empty(s)` helper; `(int)` cast → `atoi()`.
